# Assignment 4: alpha-beta-CROWN Verification

This repository contains my Assignment 4 project for Reliable and Trustworthy Artificial Intelligence.

The goal is to run alpha-beta-CROWN on an external neural network model and verify a local robustness property.

## Planned structure

- `models/`: external model files
- `configs/`: alpha-beta-CROWN YAML configuration files
- `data/`: selected input samples or specifications
- `results/`: verification logs and outputs
- `test.py`: script for running the verification experiment
- `report.pdf`: final short report
